## Charte graphique

- Bleu canard/turquoise, blanc, fonds bleu pâle, texte noir.
- Logo **non redessiné**, recadré directement dans la capture d'écran fournie. Il est visuellement identique, mais limité à la résolution de cette capture ; demander le fichier source haute définition avant mise en production.
- Photographies **recadrées à partir de la maquette fournie**, sans affirmation qu'il s'agit de photographies originales des chantiers de S.G.M Plomberie. Le site d'origine n'a pas pu être téléchargé en tant qu'archive d'assets durant cette session ; les visuels sont donc limités à la maquette.
- Bandeaux de chaque page avec animation Ken Burns (zoom avant/arrière) en boucle.
- Apparition des sections au défilement et hover sur les cartes/boutons ; menus responsive.

## Utilisation

Ouvrir `index.html` dans un navigateur ou envoyer tout le dossier sur un hébergement statique (par exemple GitHub Pages). Conserver l'arborescence.

Le formulaire Contact utilise `mailto:` : il **ouvre le logiciel de messagerie**, sans envoi serveur. Pour un envoi automatisé, relier le formulaire à un backend ou à un service de formulaires avec protection anti-spam et politique de confidentialité adaptée.
